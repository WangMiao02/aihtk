## 核心执行流：一句话触发完整链路

```

           │
           ▼ WebSocket → Gateway
┌──────────────────────────────────────┐
│  Planner（Agent Harness · LLM推理）   │
```

## 工程亮点速查

| 亮点 | 对应层 | 核心机制 |
|---|---|---|
| **自训练模型** | Layer 7 | Qwen3.5-27B GGUF · llama-server · 本地零外部依赖 |
| **Heartbeat主动感知** | Layer 2 | cron 5分钟唤醒 · 上下文感知推送 · 不等用户开口 |
| **渐进式加载** | Layer 2/4 | 索引200tok→主文件2000tok→references按需，节省85% token |
| **状态机约束** | Layer 2 | phase 硬约束流转，防止乱跳，死规则不过LLM |
| **Skill契约** | Layer 4 | 六要素·5级错误分类·分层结果·可测试·可审计 |
| **链式联动** | Layer 4 | 声明式upstream/downstream，框架自动编排，零if-else |
| **Soul人格层** | Layer 3 | 同逻辑不同输出，6套Soul配置级切换，不改Skill代码 |
| **五层持久化** | Layer 5 | 热状态/稳定层/事件层/语义层/产物层，职责解耦 |
| **RL轨迹收集** | Layer 6 | 每次执行自动记录轨迹，多指标奖励，策略可持续优化 |
| **多Agent协作** | Layer 3 | Hub Director路由·子Agent并联执行·结果聚合 |
